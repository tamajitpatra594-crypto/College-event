# Eventrix — College Event Management Portal
**Department of CSE (AIML), Institute of Engineering & Management, Kolkata**

Open `index.html` in any modern browser. No build step or local server required.

### Features
- **Modern Glassmorphic UI**: High-tech indigo & cyber palette with dark/light mode toggle.
- **Dynamic Events & Live Search**: Category filtering combined with instantaneous real-time keyword search.
- **Quick Registration Routing**: Click "Register for this" on any event card to auto-select and navigate smoothly.
- **Real-Time Live Countdown & Studio Clock**: Second-by-second countdown to the next event and live Kolkata IST clock.
- **Strict Validation Engine**: Regex-driven validation for roll numbers, mobile numbers, and emails with real-time error clearance.
- **Interactive Photo Lightbox**: Click any gallery item for an immersive modal view.
- **Responsive Architecture**: Fluid grid and flexbox layout optimized for desktop, tablet, and mobile with mobile navigation menu.

### Project Files
- `index.html` — Semantic HTML5 structure
- `css/style.css` — CSS3 design tokens, animations, responsive breakpoints
- `js/script.js` — Vanilla JavaScript interactive features
- `images/` — College logo and event photo assets
